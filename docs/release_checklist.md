# Release checklist

This checklist records the v1.2 release gates and the evidence distinction
between automated/headless checks and real GUI or native-platform runs.

## Source and data

- [x] SDL 3.4.16 and nlohmann/json 3.12.0 are pinned submodules.
- [x] SageMath 10.9, PyNormaliz 2.23, and Normaliz 3.11.0 are recorded as the
  tested generator environment.
- [x] Five Platonic and 13 Archimedean solids are generated by SageMath; the
  two snub solids use the documented chiral/Normaliz paths.
- [x] Polygon faces are preserved in `data/archimedean.json`.
- [x] CPython validation checks combinatorics, topology, geometry, and
  non-finite input rejection.
- [x] Repeated Sage generation is byte-identical.

## Linux

- [x] Clean Release configure/build completed with vendored dependencies.
- [x] CTest, validator, negative validator tests, and C++ headless tests pass.
- [x] Viewer `--selftest` loads all 18 solids.
- [ ] Real display-backed interactive run and screenshot — DEFERRED: this host
  has no `DISPLAY` or `WAYLAND_DISPLAY`.
- [x] v1.2 Linux release archive uses statically linked SDL3.

## Windows / MinGW-w64

- [x] MinGW-w64 x86_64 cross-build produces PE32+ viewer and test binaries.
- [x] SDL3 and the MinGW GCC/C++ runtime are statically linked; no SDL3, GCC,
  or C++ runtime DLL is required beside the executable (Windows system DLLs
  remain expected).
- [x] Canonical JSON is embedded in the viewer; an external JSON file is only
  needed when explicitly supplied with `--data`.
- [x] Wine compatibility self-tests pass on the Linux host.
- [x] GitHub Actions MSYS2 UCRT64 job passes build, CTest, validator, and
  viewer self-test.
- [x] v1.2 MinGW release archive fully statically links SDL3 and the GCC/C++
  runtime.
- [ ] Native Windows `--selftest` and GUI run — DEFERRED: no native Windows
  machine/session is available.

## macOS

- [x] Native Intel and Apple Silicon CI builds produce macOS app bundles.
- [x] macOS static SDL3 builds pass CTest, validator, and embedded-data
  self-test.
- [x] Universal macOS release archive is produced by the release workflow.
- [x] v1.2 macOS release archive uses statically linked SDL3.
- [ ] Apple-signed/notarized distribution — DEFERRED: signing credentials are
  not available.

## CI and documentation

- [x] Ubuntu and Windows CI jobs checkout submodules recursively.
- [x] CI avoids SageMath regeneration and makes no visual-pass claim.
- [x] README documents purpose, solids, builds, generator, controls, schema,
  screenshot placeholder, license, and dependency provenance.
- [x] Milestone evidence and handoff are recorded in `docs/status.md` and
  `docs/handoff.md`.

Deferred items are external evidence gaps, not claims of success. They should
be revisited on a display-backed Linux/Windows environment before publishing a
release screenshot or native Windows runtime statement.
