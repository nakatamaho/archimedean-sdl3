# archimedean-sdl3

archimedean-sdl3 will demonstrate all 13 Archimedean solids using
canonical polygon data generated by SageMath and a portable SDL3 viewer.
The polygon faces remain intact in JSON; the viewer will triangulate them only
at render time.

## Project status

Milestone M0 (repository bootstrap) is complete. Viewer implementation,
canonical data, and build dependencies are intentionally not present yet;
they are scheduled for later milestones.

## Supported solids

The v1 dataset will contain:

- truncated tetrahedron
- cuboctahedron
- truncated cube
- truncated octahedron
- rhombicuboctahedron
- truncated cuboctahedron
- snub cube
- icosidodecahedron
- truncated dodecahedron
- truncated icosahedron
- rhombicosidodecahedron
- truncated icosidodecahedron
- snub dodecahedron

## Build

The CMake project and SDL3 viewer are scheduled for M1. Once that milestone
is complete, the Linux build will use:

```sh
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build
ctest --test-dir build --output-on-failure
```

Windows/MinGW-w64 build instructions will be added with the supported
toolchain path in a later milestone. A headless self-test is not evidence of
an interactive visual run.

## SageMath data generation

The canonical JSON generator is scheduled for M2. Its intended invocation is:

```sh
sage -python tools/generate_archimedean.py --output data/archimedean.json
```

The ordinary viewer will load committed JSON and will not require SageMath at
runtime.

## Controls

The complete keyboard control table is specified in `CODEX.md` and will be
implemented in M7. No controls are available in the bootstrap-only tree.

## Data schema

The planned schema is versioned JSON containing generator metadata and 13
solids. Each solid preserves floating-point vertices, polygon faces as vertex
index lists, and explicit combinatorial statistics. Runtime validation and an
independent CPython validator are planned for M3 and M4.
